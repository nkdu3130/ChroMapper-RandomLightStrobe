# ChroMapper Random Light Strobe

Plugin ChroMapper pour créer des flashs aléatoires de lumières.

Installation automatique : lance `INSTALL.bat`. Il installe la DLL depuis la dernière Release dans `C:\Users\pcden\Desktop\chromapper\Plugins`.

Le plugin est conçu pour ne modifier que les événements de couleur/lumière et à ne jamais toucher aux rotations.
